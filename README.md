# rio-daily-life

AIキャラクター「りお」の日常を、X（旧Twitter）へ**無料で自動予約投稿**するためのリポジトリです。
GitHub Actions と Buffer（無料プラン）だけで動きます。

- 1日3回（朝・昼・夜）に日常のひとこと（テキスト）を投稿
- 画像付き投稿は**3日に1回・夜の枠だけ**
- 画像がない日は自動でテキストのみ（止まりません）
- 投稿文は `captions.json` で編集（30テーマ・画像ごとの専用文）

> ⚠️ このリポジトリは **Public** にしてください。画像を `raw.githubusercontent.com` から配信し、Bufferがそれを取得するためです（Privateにする場合は `IMAGE_BASE_URL` で別の公開ホスティングを指定）。

---

## 仕組み

```
GitHub Actions（毎日 JST 18:00）
   └─ daily_life_poster.py
        ├─ captions.json から投稿文を選ぶ（テーマ・直近90投稿の重複を避ける）
        ├─ images/ から画像を選ぶ（3日に1回・夜の枠だけ）
        └─ Buffer API で「枠内のランダムな時刻」に予約
              └─ Buffer が X に投稿
```

毎日18:00（JST）に実行し、次の3枠ぶんを予約します。

| 枠 | 時間帯（JST） | 内容 |
|---|---|---|
| 夜 | 20:00〜22:00 | 3日に1回は画像付き、それ以外はテキスト |
| 翌朝 | 07:00〜08:00 | テキスト |
| 翌昼 | 12:00〜13:00 | テキスト |

- 1つの枠につき投稿は1件だけ（連投による評価の低下を避けるため）。
- 時刻は枠内でランダムです（定時投稿のBot感を避けるため）。
- すでに予約済みの枠は自動で飛ばします（手動で再実行しても二重予約になりません）。
- 本文にURL・ハッシュタグ・メンションは入れません（入っていても自動で除去します）。

## フォルダ構成

```
rio-daily-life/
├─ README.md
├─ daily_life_poster.py          # 投稿予約の本体
├─ captions.json                 # 投稿文（テーマ・画像ごとの専用文）
├─ make_profile_images.py        # アイコン/ヘッダー/投稿用画像の整形ツール（ローカル用）
├─ images/                       # 投稿に使う画像（半角英数字のファイル名）
│   ├─ 01_convenience_night.jpg
│   ├─ ...
│   └─ 99_face_front.jpg         # アイコン・固定ポスト用（自動投稿しない）
├─ outputs/
│   └─ daily_life_log.json       # 予約ログ（自動生成・自動コミット）
└─ .github/
    └─ workflows/
        └─ daily-life-post.yml   # 自動実行の設定
```

`daily-life-post.yml` は必ず `.github/workflows/` の中に置いてください。

## セットアップ（初回のみ）

### 1. Bufferを用意する

1. [Buffer](https://buffer.com/) の無料プランで、投稿先のXアカウントを接続します。
2. BufferのAPI設定ページで **API Key** を発行します。
3. 投稿先の **チャンネルID** を確認します。

> **無料プランの上限**：チャンネルは**3つまで**、1チャンネルにつき予約は**10件まで**です。
> すでに別のXアカウントを2つ以上つないでいる場合、4つ目を追加すると全チャンネルが有料対象になります。接続数を確認してから追加してください。

### 2. GitHubにリポジトリを作る

1. リポジトリ名 `rio-daily-life`、**Public** で作成します。
2. このフォルダの中身をすべてアップロードします（`.github/workflows/` の階層に注意）。

### 3. Secretsを登録する

リポジトリの **Settings → Secrets and variables → Actions → Secrets** に登録します。

| 名前 | 値 |
|---|---|
| `BUFFER_API_KEY` | BufferのAPI Key |
| `BUFFER_CHANNEL_ID` | 投稿先のチャンネルID |

APIキーは**絶対にファイルへ書き込まず**、Secretsにだけ保存してください。

### 4. 動作確認（ドライラン）

1. **Actions → AIキャラ日常投稿（Buffer予約） → Run workflow**
2. `dry_run` を `true` にして実行します。
3. ログに、予約される時刻・画像・投稿文が表示されます（Bufferへは送信されません）。
4. 問題なければ、`dry_run` を `false` で実行します。以降は毎日自動で動きます。

## 画像の追加方法（週1回・2〜3枚）

画像付き投稿は3日に1回なので、**週に2〜3枚**あれば足ります。

1. **Google Flow** などで画像を作ります（基本画像を**参照画像**として渡すと顔が揃います）。
2. 必要なら投稿用の4:5に整形します。

   ```bash
   pip install pillow
   python make_profile_images.py --post flow_images --focus 0.5,0.4
   ```

   出力は `outputs_post/` に入ります（1080×1350）。
3. ファイル名を**半角英数字**にして、`images/` に入れます（例：`12_night_window.jpg`）。
   番号の小さい順に使われます。
4. `captions.json` の `images` に、画像ごとの専用文を追加します（下記参照）。登録しない場合は、汎用の `photo` の文が使われます。
5. コミットして完了です。

> 画像の投稿順：夜に合う画像（`"slot": "night"`）が先、次に時間帯の指定がない画像、最後に朝・昼向けの画像です。

### 画像の注意

- **露出のない全年齢向けの日常カットのみ**にしてください。成人向けと判定される投稿が続くと、アカウント全体がフォロー外に表示されなくなる可能性があります。
- キャラクターは**はっきり成人に見える描写**にしてください。
- 手や指、背景の看板・文字が崩れていないか、投稿前に確認してください。

## captions.json の書き方

```jsonc
{
  "themes": [                              // テキストのみ投稿の素材
    {
      "id": "m_coffee",                    // テーマID（重複しない名前）
      "slots": ["morning"],                // morning / noon / night / any
      "captions": ["朝の1杯のコーヒーで、やっと頭が動き出す☕", "..."]
    }
  ],
  "images": {                              // 画像ごとの専用文
    "01_convenience_night.jpg": {
      "slot": "night",                     // この画像に合う時間帯
      "captions": ["今日の帰り道の一枚。...", "..."]
    },
    "99_face_front.jpg": { "skip": true }  // 自動投稿しない
  },
  "photo": ["今日の一枚📷"]                 // imagesに登録のない画像用
}
```

- 投稿文は短く、日常の自然な言葉で書きます。**ハッシュタグ・URLは入れません**。
- 「？」で終わる問いかけを全体の1〜2割混ぜると、返信（Xで評価が高い反応）がつきやすくなります。
- 直近**90投稿**と同じ文、直近**10投稿**と同じテーマは使いません。
- 未使用の文が5件以下になると、実行ログに警告が出ます。**約1か月ごと**に `themes` へ文を足してください。
- 画像と同名の `.txt`（例：`01_convenience_night.txt`）を置くと、その内容が最優先で使われます。
- `images` のキー（ファイル名）は、実際のファイル名と**完全に一致**させてください。

## 設定を変える

### GitHub の Variables（Settings → Secrets and variables → Actions → Variables）

| 名前 | 既定値 | 内容 |
|---|---|---|
| `IMAGE_INTERVAL_DAYS` | `3` | 画像付き投稿の間隔（日）。`0` で画像を付けない |
| `IMAGE_SLOT` | `night` | 画像を付ける枠（`morning` / `noon` / `night`） |

### 環境変数（`daily-life-post.yml` や実行環境で指定）

| 名前 | 既定値 | 内容 |
|---|---|---|
| `POSTS_PER_RUN` | `3` | 1回の実行で予約する件数 |
| `SLOTS` | `[["morning",7,8],["noon",12,13],["night",20,22]]` | 枠の名前と時間帯（JST・開始時,終了時） |
| `BUFFER_QUEUE_LIMIT` | `9` | Bufferの予約上限（無料プランは1チャンネル10件） |
| `BUFFER_TIMEZONE_OFFSET_HOURS` | `9` | 時差（日本は9） |
| `LEAD_MIN` | `10` | 予約時刻までに最低限あける時間（分） |
| `IMAGE_BASE_URL` | GitHubのraw URL | 画像の配信元を別の場所にする場合 |
| `DRY_RUN` | `false` | `true` で送信せず内容だけ確認 |

## よくあるトラブル

| 症状 | 原因と対処 |
|---|---|
| 画像付きの日なのにテキストになる | ログに「画像URLを取得できません」と出る場合は、リポジトリがPrivate、または画像が未pushです。Publicにして、画像をコミットしてください |
| 画像付きの日なのにテキストになる（その2） | 未使用の画像がありません。`images/` に追加してください（`skip` の画像は使われません） |
| Bufferへの送信が失敗する | APIキー・チャンネルIDを確認してください。予約が10件に達していないかも確認してください |
| 「キューが上限に達している」と出る | Bufferの予約待ちが多すぎます。Bufferの管理画面で不要な予約を整理してください |
| 同じような文が続く | 「残り少ない」警告が出ていないか確認し、`themes` に文を追加してください |
| 自動実行が止まった | GitHubの仕様で、Publicリポジトリは長期間活動がないとスケジュール実行が停止する場合があります。Actionsタブで有効化し直してください。`captions.json` を更新すると防げます |
| ログのコミットで失敗する | 手動実行と定期実行が重なった可能性があります。再実行してください（同時実行は自動で順番待ちになります） |

## 運用のポイント

このリポジトリが自動でやるのは「予約投稿」だけです。アカウントを伸ばすには、次の手作業が効きます。

1. **投稿直後の2時間以内に、返信に答える**（Xの新ルールでは、投稿直後の反応が評価に大きく影響するとされています）。
2. プロフィールに**「AI生成」と明記**し、自己紹介を**固定ポスト**にする（固定ポストにリンクは貼らない）。
3. 自己紹介の文は `captions.json` の `pinned_post_example` を参考にしてください。
4. 週1回、画像を2〜3枚追加し、約1か月ごとに `themes` へ文を足す。

> Xのアルゴリズムに関する情報は、第三者の解説記事を参考にしたもので、X社の公式な保証ではありません。仕様は変わる可能性があります。
